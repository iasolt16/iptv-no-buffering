Do not test it for five minutes on a quiet afternoon and declare victory.

A better approach is to try several types of streams over the trial period:

* Watch HD content for an extended session.
* Test a 4K/UHD stream if your device supports it.
* Try the service during a busier evening period.
* Test the channels you actually care about instead of only the first few channels on the list.
* Compare Wi-Fi with Ethernet if you have that option.

This lines up closely with TiviLive's own troubleshooting recommendations, which include switching to Ethernet, restarting the router, closing other bandwidth-heavy apps, lowering stream quality and trying another channel.
